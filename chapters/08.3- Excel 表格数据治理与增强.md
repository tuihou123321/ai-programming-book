# **产品文档：AI 评论智能分析工具**

## **概述：将客户声音转化为商业洞察**

解决的问题：  
在电商和客服场景中，每天产生大量的客户评论、留言和反馈（非结构化文本数据）。传统的人工阅读和归类效率低下、耗时且容易产生主观偏差，导致企业无法及时、准确地掌握核心用户痛点。  
本工具目标：  
利用 AI 编程能力，自动批量处理海量评论文本，进行多维度标签归类和内容摘要提取，将非结构化数据转化为可量化、可决策的结构化数据（模拟 Excel 输出）。

## **核心价值与应用场景**

本工具的核心价值在于实现 **“自动化”** 和 **“智能化”**，超越了简单的人工操作和网页版 AI 功能。

| 核心价值 | 价值描述 | 目标受众 |
| :---- | :---- | :---- |
| **批量处理与效率提升** | 一键处理数百甚至数千条评论，将耗时数小时的工作缩短至数分钟。 | 运营、客服主管 |
| **多维度精准归类** | 支持一条评论打多个标签（如：既涉及“核心功能”又涉及“售后问题”），避免信息丢失，保证分析的深度和准确性。 | 产品经理、研发团队 |
| **智能摘要与洞察** | 自动提取每条评论的核心观点，快速定位关键问题，无需阅读全文。 | 市场营销团队 |
| **数据标准化** | 将零散的文本数据转化为带有标签和摘要的标准化 Excel 格式，方便进行后续的数据透视和可视化分析。 | 数据分析师 |

## **AI 归类方案细节**

AI 归类是本工具的核心智能，其分类维度是根据电动剃须刀的实际评论场景设计的，具有直接的商业指导意义。

### **分类维度（多标签支持）**

| 类别 | 描述 | 决策指导方向 |
| :---- | :---- | :---- |
| **核心功能/性能** | 评价剃须效果、动力、噪音、做工等产品物理属性。 | **产品升级与改进** |
| **售后/物流问题** | 评价物流速度、包装、客服响应、错发/漏发等交易流程问题。 | **运营流程优化** |
| **配件/设计建议** | 评价充电方式、水洗功能、续航、收纳袋等附加功能和改进意见。 | **产品规划与配件策略** |
| **价格/购物体验** | 评价性价比、促销力度、整体购物愉悦度。 | **定价与营销策略** |

## **技术实现与工作流**

本工具基于 **DashScope Qwen 模型 API** 实现，体现了 AI 编程中的 **“结构化输出”** 技巧。

### **工作流概览**

1. **输入：** 导入多条客户留言（模拟 Excel 评论列）。  
2. **数据清洗：** 程序将评论文本按行拆分，进行批量预处理。  
3. **智能分析（核心）：** 程序将每条评论和严格的 **JSON 格式要求**（包含 comment、categories、summary 字段的数组）一起发送给 Qwen API。  
4. **结果接收：** 接收 AI 返回的纯 JSON 字符串。  
5. **数据写入（输出）：** 将 JSON 数组中的多标签（如 \["功能", "售后"\]）转换为 Excel 友好的逗号分隔字符串 (功能, 售后)，并生成增强后的数据表格。

### **关键编程要点**

* **Prompt 工程：** 通过 systemPrompt 严格约束 AI 只能返回 JSON 数组，确保输出结果的可靠性。  
* **多标签处理：** 利用 JSON 数组结构来承载多标签结果，并在客户端通过 join(', ') 转换为易于 Excel 识别的格式。  
* **自动化调用：** 使用 fetch 和指数退避重试逻辑，确保批量调用 API 时的稳定性和鲁棒性。

## **使用指南**

1. **准备数据：** 将您的 Excel 文件中的“客户留言”列内容复制出来。  
2. **粘贴输入：** 将评论内容粘贴到工具的“待分析的客户留言”文本框中，确保每条评论占一行。  
3. **启动分析：** 点击“启动 AI 自动化归类”按钮。  
4. **查看结果：** 程序运行完成后，下方会生成一个增强后的数据表格，包含原始评论、AI 归类标签和 AI 摘要，可用于复制或导出。
