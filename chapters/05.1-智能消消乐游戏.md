# 实战篇：AI陪我从零打造“智能消消乐”，体验真正的“结对编程”

欢迎来到激动人心的实战章节！前面我们已经安装好了AI编程神器 CodeBuddy。现在，我们要把它从一个软件，变成我们并肩作战的“AI编程伙伴”。

本章的目标，不仅仅是做出一个“智能消消乐”游戏，更是要让你掌握与AI深度协作的正确姿势。忘掉以前那种复制粘贴代码的模式吧！你将体验到的是，你用自然语言下达指令，AI则直接在你电脑上创建文件、修改代码，仿佛一位顶级的程序员就坐在你身边，听你指挥。

准备好了吗？让我们开始这场充满未来感的“结对编程”之旅。

## 第一步：搭建“施工现场”——创建并打开你的项目

专业的程序员开工前，都会先整理好自己的工作区。我们也要养成这个好习惯。

1.  **在电脑里建个家**：首先，在你电脑的任意位置（比如桌面），创建一个新的文件夹。

2.  **给它取个英文名**：为了规范，我们给文件夹取一个全英文、用下划线连接的名字。比如：`my_candy_crush_game`。

3.  **用CodeBuddy打开它**：现在，打开CodeBuddy软件。在顶部的菜单栏，找到 `文件(File)` -\> `打开文件夹...(Open Folder...)`。

    [图片占位符：CodeBuddy顶部菜单栏，高亮“打开文件夹...”选项]

4.  **选择你的文件夹**：在弹出的窗口中，找到并选择我们刚刚创建的 `my_candy_crush_game` 文件夹，然后点击“打开”。

做完这一步，你会看到CodeBuddy的左侧文件浏览器区域，显示了你的文件夹名字，不过里面现在还是空的。这非常重要，这一步相当于告诉了你的AI伙伴：“嘿，接下来我们所有的工作，都在这个文件夹里进行！”

## 第二步：下达“创世指令”——一句话生成整个项目

现在，我们的“施工现场”已经准备就绪。接下来，就是见证奇迹的时刻。我们要像产品经理一样，把对游戏的所有构想，清晰地传达给AI。

一个好的指令，应该包含完整的蓝图。请记住，你描述得越清晰，AI执行得就越精准。

**请复制下面这段精心设计的“创世指令”，粘贴到CodeBuddy的聊天框里并发送：**

```
你是一位资深的前端游戏开发专家。

请在这个项目文件夹中，帮我创建一个经典的“消消乐”网页游戏。

具体需求如下：

1.  **创建文件**：请自动创建`index.html`, `style.css`, 和 `script.js` 三个文件来存放代码。

2.  **HTML (结构)**：
    * 在 `index.html` 中，创建一个 `div` 作为游戏主容器，并在其中生成一个 8x8 的游戏网格。
    * 在游戏区域上方，设置一个标题和计分板，初始分数为0。

3.  **CSS (样式)**：
    * 在 `style.css` 中，让游戏容器居中显示，并为网格和方块添加清晰的边框。
    * 随机生成至少五种鲜明的颜色，用于填充方块。
    * 为方块添加简单的动画效果，如消除时的淡出效果。

4.  **JavaScript (逻辑)**：
    * 在 `script.js` 中，实现核心玩法。游戏开始时，用随机颜色的方块填满网格，并确保初始状态没有可消除的组合。
    * 玩家可以通过鼠标拖拽来交换相邻的两个方块。
    * 交换后，检测并消除所有可消除的同色方块（横向或纵向三三消除），并增加分数。
    * 实现方块下落和顶部新方块补充的逻辑。
    * 如果交换后不能消除，方块则自动换回原位。
```

**发送指令后，请把目光聚焦在CodeBuddy左侧的文件浏览器上！**

你会看到令人惊叹的一幕：AI不再是给你一段段的代码，而是像一个勤奋的机器人，**直接在你的文件夹里创建了 `index.html`, `style.css`, `script.js` 这三个文件，并把所有代码自动写了进去！**

[图片占位符：左侧文件浏览器中，自动出现了三个新创建的文件，并且文件图标不再是空白，表示已有内容]

这就是AI IDE的强大之处——它直接在你的项目上动工，省去了所有中间环节。

## 第三步：竣工验收——第一次运行你的游戏

项目已经由AI自动“施工”完毕。现在，让我们来“验收”一下成果。

1.  **找到启动文件**：在CodeBuddy左侧的文件列表中，找到 `index.html`。
2.  **在浏览器中打开**：在 `index.html` 上点击鼠标右键，在弹出的菜单中选择“在浏览器中打开”（Open in Browser）或类似选项。

你的电脑浏览器会自动弹开，一个功能完整的消消乐游戏赫然出现在眼前！快去亲自玩一下，感受拖动、消除、得分的快感。这可是你“指挥”AI创造出来的第一个作品！

## 第四步：迭代升级——与AI“对话式”优化项目

你的游戏很棒，但我们还能让它更酷。与集成在IDE里的AI协作，迭代升级就像和同事聊天一样简单。由于你们在同一个项目“频道”里，它完全理解当前的上下文，你不需要重复解释。

#### **进化一：增加一个60秒倒计时**

我们想让游戏更刺激。直接在同一个聊天框里，继续对它说：

```
很好，现在给游戏增加一个60秒的倒计时功能。时间一到，游戏就结束，并且弹出一个提示框告诉我最终得分。
```

**发送！**

这次，你不需要做任何复制粘贴。你只需要观察。CodeBuddy会告诉你它正在“思考”或“修改文件”，几秒钟后，它会提示你“任务完成”。**它已经自动修改了你本地的 `script.js` 文件！**

现在，回到你的浏览器，**刷新一下页面**。看到了吗？计分板旁边是不是多了一个倒计时？这就是与AI无缝协作的体验！

### **进化二：更换游戏“主题”**

方块太普通？我们来个甜蜜的糖果主题。继续对它说：

```
把游戏的美术风格换成糖果主题吧。将方块变成圆角的糖果样式，再把背景美化一下。
```

**发送！**

CodeBuddy会心领神会，这次它会自动去修改 `style.css` 文件。当它完成后，你只需要**再次刷新浏览器**，你的“方块消消乐”就华丽变身为“糖果传奇”了！
