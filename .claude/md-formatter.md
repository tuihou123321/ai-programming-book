✨**输出要求**

请严格遵循以下所有规则，对输入的Markdown文本进行格式化处理，并将整理后的完整内容放在一个Markdown代码块中输出。


**一、 层次与标题 (Markdown 语法)**

1.  **一级标题**: 对应章节标题，使用 Markdown H1 语法。格式：`# 第X章 标题内容`。

2.  **二级标题**: 对应节标题，使用 Markdown H2 语法。格式：`## X.X 标题内容`。

3.  **三级标题**: 使用 Markdown H3 语法。格式：`### X.X.X 标题内容`。

4.  **四级标题**: 使用 Markdown H4 语法。格式：`#### X.X.X.X 标题内容`。

5.  **段内要点**: 对于叙述性的、有顺序的句子列表，使用有序列表。格式：`1. ...` `2. ...`。


**二、 文本样式与特殊元素**

1.  **辅助提示**: 对于"注意"、"提示"等辅助内容，使用加粗的标题后接正文。格式：`**注意：**这是一个提示信息。`

2.  **代码块**: 所有代码片段必须使用Markdown的围栏代码块（fenced code blocks）进行包裹。

3.  **图片与说明（重要）**:

    * **兼容性换行**: 为了兼容Typora等编辑器，图片标签 `![...](...)` 的**上一行**、**图片标签与说明文字之间**、以及说明文字的**下一行**都必须是**空行**。

    * **保留路径**: 必须完整保留原始的Markdown图片引用 `![描述](路径)`。

    * **说明格式**: 在图片下方另起一行添加图片说明。说明的命名规则为 `图X.X 图片的简单描述` (例如: `图1.1 对话框`)。图的序列号应根据章节和上下文逻辑进行正确编排。

    * **完整结构**:

        ```

        (此处应有一个空行)

        ![图片描述](图片路径)

        

        图X.X 图片的简单描述

        (此处应有一个空行)

        ```



**三、 段落格式**

1.  **首行缩进**: 所有正文段落（标题、代码块、列表、图片说明除外）的首行，都需要添加**两个全角空格**（`　　`）进行缩进。



**四、 细节表述规范**

1.  **操作步骤**:

    * 统一使用"执行……命令"或"选择……命令"。

    * 对于对话框、窗口，统一使用"打开"。

    * 对于快捷菜单、下拉列表，统一使用"弹出"。

    * 将所有"点击"修正为"单击"，右键操作明确表述为"右击"。

2.  **人称**:

    * 通篇采用第三人称叙述。

    * 严禁使用"我们"、"我"、"你们"、"你（您）"等第一、二人称。

3.  **标点**:

    * 检查并移除双引号内各项之间的顿号。例如，将 `"A"、"B"、"C"` 修改为 `"A" "B" "C"` 或 `A、B、C`。

4.  **数学符号规范**:

    * 将LaTeX格式的数学符号转换为标准Unicode符号：
      - `$\ge$` → `≥` (大于等于号)
      - `$\le$` → `≤` (小于等于号)  
      - `$\ne$` → `≠` (不等于号)
      - `$\pm$` → `±` (正负号)
      - `$\times$` → `×` (乘号)
      - `$\div$` → `÷` (除号)

5.  **专业术语统一**:

    * "登陆" → "登录"
    * "点击" → "单击"  
    * "右键点击" → "右击"
    * "自己的" → "自身的"
    * "你的" → "用户的"
